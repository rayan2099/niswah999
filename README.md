# Niswah

A mobile application that helps women track their period and health metrics.

## Project workspace in Obsidian

Open this repository root as an Obsidian vault, then open [Niswah project home](project-hub/Home.md). The workspace connects existing documents, all feature modules, engineering, review, quality, and release material without duplicating source content. See [setup instructions](project-hub/Setup.md) and [agent workflow](project-hub/Agent-Workflow.md).
