# Citation Contract

Every authoritative answer must be traceable:

AI answer
→ knowledge item version
→ source ID
→ exact source locator

Citation fields:
- citation_id
- knowledge_id
- knowledge_version
- source_id
- source_display_name
- locator
- URL/reference
- language
- Madhhab if applicable

The backend supplies citation metadata. The LLM must not invent page numbers, books, URLs, scholars, or source titles.
