# Fiqh Evidence Extraction Method

## Goal
Turn each Madhhab-specific atomic question into a scholar-reviewable evidence record without treating model memory or a generic web answer as a ruling.

## Evidence standard
For each atom record:
1. exact work/title and author
2. stable web locator
3. printed page/section when visible
4. concise source-supported proposition
5. secondary corroborating source where available
6. uncertainty/conflict note
7. status

## Status vocabulary
- LOCATOR_VERIFIED — primary locator directly supports the proposition
- PARTIAL_EVIDENCE — source supports part of the atom but a narrower ruling/condition remains unresolved
- SCHOLAR_CLARIFICATION_REQUIRED — sources expose a Madhhab-internal nuance or the product question needs a precise relied-upon formulation
- PRIMARY_LOCATOR_NEEDED — proposition is plausible/expected but an exact primary locator has not yet been established

## Copyright discipline
This repository stores source URLs, locators, and concise paraphrases. It does not bulk-copy copyrighted hosted editions or long web passages. A reviewer should consult the linked source directly.

## Approval gate
Research extraction is not approval. Every Fiqh proposition remains PENDING_SCHOLAR_REVIEW until a qualified Madhhab-aware scholar approves or edits it.
