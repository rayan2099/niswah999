selected from 148 total captured. The full set (every onboarding step,
every intermediate state, for every persona run including earlier,
superseded iterations) is not committed — they are large, mostly
redundant binary artifacts, gitignored under `acceptance/` in the
repository root, and were available locally under
`acceptance/screenshots/pr4/` and `acceptance/screenshots/explore/`
during this session.
