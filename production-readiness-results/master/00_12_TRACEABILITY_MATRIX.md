This was root-caused, not assumed — `main`'s own `onboarding_screen.dart` was read directly (`git show main:...`) and confirmed to contain the exact old 4-choice Madhhab grid the owner's screenshot showed. No merge or branch action was taken unilaterally; this is reported for an explicit owner decision on how and when to bring `main` current, since merging shared branch state is a hard-to-reverse action outside this engagement's authority to decide alone.
